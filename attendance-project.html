Student Attendance System Using Blockchain

An automated attendance management system combining RFID-based student identification with blockchain technology for secure and tamper-resistant attendance records.

Explore Project ↓ View Project Report ↗

01 / OVERVIEW

About the Project

Traditional attendance systems can be time-consuming, prone to manual errors and vulnerable to unauthorized modifications. This project proposes an automated attendance solution using RFID technology and blockchain.

A Raspberry Pi 4 processes student RFID scans and communicates with a smart contract deployed on a local Ethereum blockchain using Ganache. An OLED display provides immediate feedback to the student.

02 / THE CHALLENGE

Problem Statement

Conventional attendance mechanisms may experience proxy attendance, manual recording errors, data manipulation and a lack of transparency.

The project addresses these challenges by combining physical RFID-based identification with blockchain record-keeping to improve security, automation and accountability.

03 / TECHNOLOGY

Tools & Components

Raspberry Pi 4 RFID RC522 OLED Display Ganache Ethereum Blockchain Smart Contracts SPI I2C

04 / WORKFLOW

How the System Works

01

RFID Scanning

The student scans their RFID tag near the RFID RC522 reader.

02

Data Processing

The Raspberry Pi 4 receives and processes the scanned RFID information.

03

Blockchain Recording

Attendance information is sent to a smart contract on the Ganache Ethereum blockchain.

04

OLED Feedback

The OLED display provides messages such as Attendance Marked or Access Denied.
